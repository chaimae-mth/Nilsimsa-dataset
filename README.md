# Nilsimsa-dataset

# BLE device-type identification dataset

Dataset for the paper "Cross-Layer BLE Device-Type Identification via
Locality-Sensitive Hashing for IoT Security".

Real dataset of four BLE devices types-manufacturers (two identical Thermometer-Govee, two identical Plug-Shelly, two identical Motion detector-Shelly,  four identical Govee-Lightbulb)
Synthetic dataset of 100 device types-manufacturers

Stored dataset : 10 000 Json file is composed of 2500 of real testbed records + 7500 synthetic records
Test dataset: 5000 Json file is composed 2500 synthetic + 2500 real devices
